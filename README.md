## Projects

- [Sprout](https://github.com/philipp-sz/Sprout) is a series of small language models implemented from scratch in PyTorch. The largest, Sapling (134M parameters), was pretrained on 15B tokens on a single 12 GB GPU. It averages 33.5% on four benchmarks, ahead of GPT-2 Small (30.8%).
- [Tenzor](https://github.com/philipp-sz/tenzor_python) is a deep learning framework built on NumPy. It implements automatic differentiation and a PyTorch-like `nn` API. A small MLP trained with it reaches 97.2% test accuracy on MNIST.
- [Solar System Simulation](https://github.com/philipp-sz/solar_sim_python) is a real-time 3D simulation of the Sun and eight planets in Python with ModernGL. Gravity is integrated with velocity Verlet, and the relative energy error after one simulated year is about 5.7 · 10⁻⁸.
- [WhisperClaude](https://github.com/philipp-sz/WhisperClaude) is a local dictation tool for Windows. A tap on Left Ctrl records, and the transcribed text is pasted into the focused app. It runs Whisper on the user's own machine and handles German and English. It was built with Claude Code, which the name refers to.
